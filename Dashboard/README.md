# Trading Dashboard Project

A modern, responsive trading dashboard application built for portfolio management and stock trading operations.

## Features

- **Portfolio Management** - Track your holdings, positions, and funds
- **Real-time Trading** - Buy and sell stocks with interactive action windows
- **Data Visualization** - Interactive charts including doughnut charts and vertical graphs
- **Watchlist Management** - Monitor your favorite stocks
- **Order Management** - Track all your trading orders
- **Portfolio Summary** - Comprehensive overview of your investments
- **Responsive Design** - Works seamlessly on desktop and mobile
- **Real-time Updates** - Live portfolio and market data

##  Tech Stack

- **Frontend**: React.js, HTML5, CSS3, JavaScript
- **UI Framework**: Tailwind CSS / Material-UI
- **Charts**: Chart.js / D3.js / Recharts
- **Backend**: Node.js, Express.js
- **Database**: MongoDB / PostgreSQL 
- **Authentication**: JWT tokens
- **State Management**: Redux / Context API
- **Build Tool**: Vite / Create React App

### Prerequisites

- Node.js (v14 or higher)
- npm 
- Git

## To start the server
- Write on the Terminal = npm start
- To view the Bar Graph part, you need to simulatneously start both the server 
i.e Backend and the Dashboard Part
- To run the Terminal in the Dashboard part first write cd/frontend2 and then start the server using npm start.
