## Zerodha-Clone-Frontend

## 🚀 About This Project

This project is a complete frontend recreation of the Zerodha trading platform, built from scratch using pure HTML5, CSS3, and Vanilla JavaScript. Every detail has been carefully crafted to mirror the original platform's design philosophy - clean, minimal, and user-focused.
Key Elements

  - 🎯 Pixel-perfect design - Matches original Zerodha aesthetics
  -📱 Mobile-first approach - Responsive across all devices
  -⚡ Lightning fast - No heavy frameworks, pure vanilla JS
  - 🎨 Modern UI/UX - Contemporary design principles
  - 🔧 Production-ready code - Clean, maintainable structure

## ✨ Features

## 🎨 Design & UX
